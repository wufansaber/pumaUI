# Puma 9980 Review Demo

These files are simulated training data. They do not contain production wafer data.

- `PUMA_DEMO_LOT_W01.klarf`: importable KLARF result with representative defects.
- `defects.csv`: the same small defect set in a readable table.
- `review_manifest.json`: lot, wafer, recipe, and file relationships used by the demo.

The application also creates two deterministic in-app results for wafers W01 and W02
when Review is opened. Existing operator results are preserved.
