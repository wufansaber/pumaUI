PUMA_9980_VALIDATION

This directory belongs to the bundled full-workflow validation recipe.
It contains simulated data only and is not tied to production equipment.

Recipe contents:
- 300 mm patterned wafer, 180 degree orientation
- completed two-site alignment and centered wafer map
- Test 1 with trained Fourier Filter and Light Training
- Test 2 with Light Training and no Fourier Filter requirement
- Care Areas, Sample Plan, Sensitivity, Lot Plan, and WPP defaults
- run setup for lot PUMA_VALIDATION_LOT, wafer W01
- bundled KLARF defect data for Review demonstrations

Open Local Recipes and select PUMA_9980_VALIDATION.
